Informe os dados para seu Certificado Digital:

O nome social é destinado para pessoas transgênero que ainda não fizeram a atualização da documentação pessoal e deverá ser usado para dar início ao atendimento. É importante salientar que no momento da gravação, será feita a validação dos dados com o nome de registro (nome civil) que consta no documento apresentado. Isso se faz necessária pelo fato de que este é o nome que está presente nas bases de dados dos sistemas que possibilitam a autenticação/acesso com o Certificado Digital.
